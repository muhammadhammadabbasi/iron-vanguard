# Mixamo animations

Upload the Mixamo animation files here (GitHub: **Add file → Upload files**, drag and drop).

Mixamo download settings for every animation:
- Format: **FBX Binary (.fbx)**
- Skin: **Without Skin**
- Frames per second: **30**
- Tick **In Place** for walk / run / crouch animations

The file name Mixamo gives (for example `Rifle Idle.fbx`) is fine; there's no need to rename.
